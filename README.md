# AI Thumbnail Editor — Releases

Release binaries and the Sparkle update feed for AI Thumbnail Editor.

- Feed: `thumbnail_editor_appcast.xml`
- Builds are attached to each tagged release.

Builds are ad-hoc signed rather than notarised, so on first launch macOS will
warn about an unidentified developer. Right-click the app and choose **Open**
once to allow it. Updates after that are verified by Sparkle's EdDSA signature.
